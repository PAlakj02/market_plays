Five models, eight market regimes, one honest scoreboard.

Every number on this page comes from a real, walk-forward-tested prediction -- not a demo, not a mockup. The goal was never to prove the models beat the market; it was to find out, and report it either way.

Linear Regression

Explainable baseline. Refit daily on all prior data: 8 technical-indicator features (moving averages, RSI, MACD, 20-day volatility) predicting the next 5-day log return.

ARIMA(5,0,0)

Classical time-series baseline fit on log returns, updated (not refit) as each new day arrives. No exogenous features, pure autocorrelation structure.

Random Forest

Tree ensemble on the same 8 features, refit every 20 trading days on an expanding window. Can capture nonlinear interactions the linear baseline can't.

XGBoost

Gradient-boosted trees, same features and refit cadence as the Random Forest, for a second nonlinear comparison point.

LSTM

1-layer, 32-unit sequence model over the last 30 days of features (not a single day's snapshot). Trained once per window (periodic refit only for the multi-year Bull Run); each number here is averaged across 5 independently-seeded runs, since a single run wasn't stable enough to trust on its own.

The full picture, one index.

It's not just the index.

For each model/window, the share of assets in the basket where directional accuracy was statistically significantly better than a coin flip (green) vs. significantly worse (red). The rest were not statistically distinguishable from chance.

Reading the scoreboard

Crashes are where models break down

  • Dot-com crash: Random Forest wrong on 18.2% of the basket
  • Demonetization: Linear Regression wrong on 20% (small sample -- 34 predictions, a hint rather than a strong result)
  • 2024–25 correction: XGBoost's worst window, wrong on 25% of the basket

Trending markets look far more learnable

  • Bull Run (2003–07): the strongest result on this page -- Random Forest right on 66.7% of the basket, XGBoost 50%, ARIMA 58.5% directional accuracy on the index alone
  • Post-COVID rally: Random Forest right on 30%, wrong on 0%

The core pattern

  • Random Forest and XGBoost find real structure in calm or trending markets -- but it's regime-specific, and backfires exactly when a regime breaks (2008, COVID, 2016, the 2024–25 correction)
  • Linear Regression never becomes confidently wrong -- it just goes weak and stays there

LSTM tells a different story

  • Disagrees with every other model on the Bull Run: 0% right, 18.2% wrong, versus 50–67% right for everyone else
  • Right on 16.7% of the basket for the Recovery Rally, evenly split on Post-COVID (25% right, 25% wrong)
  • A single training run wasn't even consistent with itself -- one early test flipped between "no effect" and "significantly wrong" on identical code. Every LSTM number here is now averaged across 5 separately-trained runs, not one, so what's shown is real and repeatable

Coverage

  • 8 of 9 market windows are covered by all five models, using real historical data (1998–2026) and the same testing method throughout
  • Dot-com crash isn't covered by LSTM yet -- that period starts before this data goes back
  • A regime-detection layer isn't built yet either
