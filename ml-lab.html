Four models, three market regimes, one honest scoreboard.

Every number on this page comes from this project's own walk-forward, no-lookahead evaluation (src/forecasting.py), not a demo, not a mockup. The goal was never to prove the models beat the market; it was to find out, and report it either way.

Linear Regression

Explainable baseline. Refit daily on all prior data: 8 technical-indicator features (moving averages, RSI, MACD, 20-day volatility) predicting the next 5-day log return.

ARIMA(5,0,0)

Classical time-series baseline fit on log returns, updated (not refit) as each new day arrives. No exogenous features, pure autocorrelation structure.

Random Forest

Tree ensemble on the same 8 features, refit every 20 trading days on an expanding window. Can capture nonlinear interactions the linear baseline can't.

XGBoost

Gradient-boosted trees, same features and refit cadence as the Random Forest, for a second nonlinear comparison point.

Reading the scoreboard

Crashes and shocks are where models break. Dot-com crash: Random Forest flips to 18.2% of the basket significantly worse than random. Demonetization: Linear Regression hits 20% significantly worse (n is small here, 34 predictions, so treat it as a hint, not a strong result). 2024–25 Correction: XGBoost is significantly worse on 25% of the basket, its worst showing of any window trained.

Sustained trends are a different story. The Bull Run (2003–07) is the strongest calm-market result on this page. Random Forest hits 66.7% of the basket significantly better than random, XGBoost 50%, and even ARIMA reaches 58.5% directional accuracy on the index alone. The Post-COVID rally (2020–21) shows a similar pattern: Random Forest 30% significantly better, zero percent significantly worse. Momentum, in other words, looks far more learnable than a turning point.

Same pattern as the original 2008/COVID finding, now with 6 more data points: tree-based models find more real-looking structure in trending or calm conditions, but that structure is regime-specific. It's most likely to backfire exactly when a regime breaks (2008, COVID, the 2024–25 correction, the 2016 policy shock). Linear regression's failure mode stays consistent across all 8 windows: it rarely becomes confidently wrong, it just goes weak/silent instead.

All 8 windows have real trained models (Linear Regression, ARIMA, Random Forest, XGBoost), on real yfinance data (1998–2026), using the same walk-forward, no-lookahead method throughout. An LSTM/GRU sequence model and a regime-detection layer (k-means or HMM on volatility/return features) aren't represented on this page.
