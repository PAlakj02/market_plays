Where the model was wrong: the actual numbers.

Copied verbatim from this project's own evaluation run (models/*_IDX_BSESN_covid_crash.json). n=51 trading days, 20 Feb–30 Apr 2020, trained on data strictly before the test window.

Headline finding: Random Forest and XGBoost's directional accuracy, which beats or matches chance in calm 2017 conditions, flips to significantly worse than random during COVID (p = 0.0013 and p = 0.0078). ARIMA drops from 66.9% directional accuracy in the calm window to 31.4% in COVID. Only linear regression avoids becoming confidently wrong, it goes weak/silent instead, a genuinely different failure mode. This holds beyond the index too: a Random Forest/XGBoost run on RELIANCE.NS during COVID lands at 29.4% directional accuracy, also significant (p = 0.0033). LSTM sits apart from all of them here: 41.2% directional accuracy, not statistically distinguishable from chance (p = 0.21) -- neither confidently right nor confidently wrong, unlike the tree models.
